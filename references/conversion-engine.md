# Conversion Engine

## Attention is not conversion

A campaign needs a plausible path from interest to action.

Map:

**attention → relevance → proof → desire → CTA → follow-up → sale/activation**

## One Primary Action

Choose one main CTA per campaign.

Examples:

- buy;
- start trial;
- book demo;
- request quote;
- join waitlist;
- message;
- reserve;
- install;
- create account.

Secondary links may exist, but they should not compete with the main decision.

## Offer architecture

Define:

- target buyer;
- core problem;
- promised transformation;
- product/service;
- price;
- value framing;
- proof;
- risk;
- risk reversal;
- timing;
- bonus/bundle;
- CTA.

## Promotion engineering

Promotion is not synonymous with discounting.

Possible levers:

- deadline;
- early access;
- bundle;
- upgrade;
- implementation help;
- onboarding;
- bonus;
- priority;
- limited cohort;
- real inventory limit;
- trial;
- guarantee;
- credits;
- free setup;
- installation.

Prefer increasing value before destroying margin.

## Buyer-language conversion

Replace internal language with buyer meaning.

Instead of:

> AI-powered workflow orchestration.

Say:

> The follow-up happens automatically, so your team stops chasing the same task manually.

Use words found in:

- sales calls;
- DMs;
- reviews;
- tickets;
- churn interviews;
- comments;
- emails;
- support conversations.

## Objection mining

For each repeated objection, create at least one asset:

- FAQ;
- demo;
- comparison;
- proof;
- email;
- sales script;
- landing-page section;
- product change.

## Metrics

Prioritize:

1. incremental revenue;
2. qualified pipeline;
3. qualified leads;
4. demos/bookings;
5. trials;
6. activation;
7. conversion;
8. retention/repeat purchase;
9. referral.

Use reach, impressions, likes and follower count as diagnostic metrics, not end goals.

## Stop/change signals

Every campaign should define a falsification signal.

Examples:

- strong CTR but weak landing-page conversion → message/offer mismatch;
- many trials but weak activation → onboarding/product issue;
- strong sales but high refund/churn → expectation or product issue;
- weak reach but strong conversion → distribution problem;
- high reach and low qualified action → audience mismatch.

Do not automatically solve every weak result by adding more reach.
